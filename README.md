# Portfolio d'Illane SIDIBE

Site statique (HTML / CSS / JavaScript) publié avec GitHub Pages.

Adresse : https://angrykate.github.io/

## Tester en local
Ouvrir `index.html` dans le navigateur, ou lancer `python -m http.server`
dans ce dossier puis ouvrir http://localhost:8000.

## Structure
- `index.html` : la page unique
- `css/` : styles (base, layout, components, animations)
- `js/` : scripts (menu, apparitions, compteurs, agrandissement d'images, bande de projets, curseur, bande de technologies, conversation WhatsApp, secrets, données des projets)
- `fonts/` : polices auto-hébergées (Instrument Serif, Plus Jakarta Sans, JetBrains Mono)
- `images/` : photo et captures des projets (WebP optimisé)
- `assets/` : CV téléchargeable

## Contenu
Site personnel présentant cinq projets (IA, bases de données, applications). Technologies : HTML, CSS et JavaScript natifs, sans framework ; hébergement GitHub Pages.

## Structure des scripts
`words.js` (titres mot par mot), `about.js`, `method.js`, `fx.js` (tilt, boutons aimantés, horloge de Lomé, courbe de prévision au scroll), `css/sections.css` (sections À propos, Méthode, Contact).
